# tracestack

Trace structured JSON stack payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/tracestack/

## Install / run

```bash
git clone https://github.com/theworker02/tracestack.git
cd tracestack
node src/cli.js
node --test
```
